# Прогулка по Лобачевскому

Интерактивная трёхмерная модель пространства Лобачевского в браузере. По ней можно ходить
от первого лица, как в игре. Все построения выведены из формул курсовой работы
«Интерпретация утверждений геометрии Лобачевского в модели Кэли — Клейна и их
компьютерная визуализация» (Булгакова М. В., МПГУ, 2026).

## Миры

| № | Мир | Что показывает |
|---|---|---|
| 1 | Луг Лобачевского | плоскость с дорогой, деревьями и домами; флажки, сумма углов и площадь треугольника, «квадрат», который не замыкается, угол параллельности Π(h) |
| 2 | Пятый постулат | прототип стелса: охрана с фонарями, обнаружение по угловому размеру sin α = sh r / sh d |
| 3–5 | Мозаики | прямоугольные додекаэдры {5,3,4}, кубы с углом 72° {4,3,5}, кубы с вершинами на абсолюте {4,3,6} (п. 6.2–6.3) |
| 6 | Евклидовы кубы | то же в обычном пространстве, для сравнения |
| 7 | Дом на орисферах | комната с полом-орисферой, h = ln 2 (п. 6.4) |
| 8 | Мозаика плоскости | прямоугольные пятиугольники {5,4} и карта в модели Кэли — Клейна |

Управление: мышь — смотреть (щелчок по сцене), W A S D — идти, Пробел и C — вверх и вниз
(в стелсе C — пригнуться), Shift — быстрее, F — флажок, R — к началу, 1–8 — миры,
`` ` `` — отладочная панель. На телефоне — джойстик и кнопки ▲ ▼ ⚑.

## Как устроено

Точки пространства — векторы гиперболоида ⟨X,X⟩ = −1 в R^{3,1}, движения — матрицы,
сохраняющие форму ⟨X,Y⟩ = x₁y₁ + x₂y₂ + x₃y₃ − x₀y₀. Видеокарта для каждого пикселя
выпускает луч-геодезическую X(t) = ch t · P + sh t · V и шагает по нему на расстояние
до ближайшего предмета (raymarching). Мозаики получаются складыванием луча в ортосхему
группы отражений Кокстера: одна клетка изображает всё пространство.

```
index.html            страница и разметка интерфейса
styles/app.css        оформление
data/worlds.json      описания миров: тексты, формулы, задания
src/main.js           загрузка, кадр, рендер
src/app.js            общее состояние: текущий мир, камеры, ввод
src/engine/math.js    линейная алгебра в R^{3,1}: движения, отражения, расстояния
src/engine/webgl.js   WebGL2, сборка шейдеров с #include
src/engine/camera.js  движение игрока и матрица камеры
src/engine/input.js   клавиатура, мышь, касания
src/world/geometry.js ортосхемы групп [p,3,r] и [5,4], складывание камеры
src/world/cameras.js  начальные положения в мирах
src/world/meadow.js   луг: предметы, флажки, треугольник, «квадрат»
src/game/stealth.js   охрана, конусы фонарей, обнаружение
src/ui/hud.js         панель, показатели, переключение миров
src/ui/devpanel.js    отладочная панель
src/shaders/*.glsl    шейдеры миров; base.glsl и normal.glsl подключаются через #include
test/smoke.mjs        проверка: все миры открываются без ошибок
```

Сборка не нужна: это ES-модули, страница работает с любого статического сервера.

```
python3 -m http.server 8000      # затем открыть http://localhost:8000
node test/smoke.mjs              # нужен playwright
```

Открыть `index.html` двойным щелчком нельзя: браузер не загружает модули и шейдеры
по адресу `file://`.

пуше в `main`. В настройках репозитория нужно один раз выбрать Settings → Pages →
Source: GitHub Actions.
