# Гиперболические поверхности: сфера, орисфера, эквидистанта

В этой ветке сохранена версия приложения, где три поверхности собраны на вкладках в одном окне. Основная версия, только с гиперболической сферой, лежит в ветке `main`.

Все построения сделаны в модели Бельтрами–Клейна.

## Вкладки

- **Гиперболическая сфера:** центр по трём осям (от −0.6 до 0.6), евклидов радиус (от 0.05 до 0.8), кнопка скрытия осей.
- **Орисфера:** углы φ и θ, определяющие идеальную точку, радиус орисферы (от 0.05 до 0.9), кнопка скрытия геодезических.
- **Эквидистанта:** углы φ и θ нормали геодезической плоскости, расстояние h (от 0.1 до 2.5), кнопка скрытия плоскости.

## Запуск

Зависимости (`requirements.txt`) и команды запуска такие же, как в README ветки `main`, там же заметки про Termux и Python 3.14.
