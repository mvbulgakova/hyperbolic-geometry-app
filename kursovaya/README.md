# Курсовая работа

**Интерпретация утверждений геометрии Лобачевского в модели Кэли — Клейна
и их компьютерная визуализация.** Булгакова М. В., МПГУ, Институт математики
и информатики, кафедра геометрии им. Л. С. Атанасяна, 2026.

## Состав

| Файл | Что внутри |
|---|---|
| `main.tex` | преамбула, оформление по ГОСТ 7.32-2017 |
| `titul.tex` | титульный лист |
| `vvedenie.tex`, `zaklyuchenie.tex` | введение и заключение |
| `glava1.tex` … `glava7.tex` | главы 1–7 |
| `figs.py`, `figs2.py` | скрипты, строящие рисунки в `fig/` |
| `klein_surfaces.py` | модели поверхностей (глава 6.6) |
| `fig/` | готовые рисунки (PDF) |
| `docs/kursovaya_chernovik_4.pdf` | собранный черновик 4 |
| `docs/gost_7.32_2017.pdf` | ГОСТ 7.32-2017 для сверки оформления |

## Сборка

```
latexmk -xelatex main.tex
```

Нужен шрифт Liberation Serif (или Times New Roman). Рисунки пересобираются
командами `python figs.py` и `python figs2.py`.
